# 🍔 Swiggy Hyperlocal Success Predictor
**An AI-Driven Framework for Restaurant Site Selection & Performance Optimization**

## 📌 Project Overview
This project analyzes 8,000+ restaurants to solve a critical business problem: **How can a new entrant identify high-ROI locations and out-compete established players?** By combining K-Means Clustering and Multiple Linear Regression, we identified the mathematical "DNA" of success in the food delivery market.

## 🚀 Key Business Insights
* **The Quality Pivot:** Improving a rating by **0.5 stars** is **36x more effective** than a ₹100 price cut.
* **Strategic Gaps:** Identified **Chembur** and **Pitam Pura** as "Gold Mine" localities (High volume + Low current quality).
* **AI Personas:** Grouped the market into 5 distinct clusters, shifting strategy from "Cuisine-based" to "Consumer-intent-based."

## 🛠️ Tech Stack
- **Languages:** Python (Pandas, NumPy)
- **Machine Learning:** Scikit-Learn (K-Means, Linear Regression)
- **Visualization:** Plotly, Seaborn (Interactive Dashboards)
- **Geospatial:** OSMnx (Proximity Analysis)
